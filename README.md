# 🚀 Angular (v19+) - Do Zero ao Avançado

Repositório contendo os projetos, exercícios e códigos desenvolvidos ao longo do curso de **Angular (v19+)**, cobrindo desde os fundamentos básicos até técnicas avançadas de arquitetura e micro-frontends.

---

## 📌 Sobre o Projeto

Este repositório reúne o aprendizado prático focado na construção de aplicações web modernas, escaláveis e de alta performance utilizando a versão mais recente do framework Angular. Os projetos foram desenvolvidos com foco em código limpo, reutilização de componentes, boas práticas de segurança, desempenho e arquitetura distribuída.

---

## 🎓 O que foi aprendido e praticado

* **Aplicações completas em Angular:** Desenvolvimento do básico ao avançado para projetos modernos.
* **Design & Interfaces:** Construção de interfaces responsivas e elegantes com **Material Design** e **TailwindCSS**.
* **Consumo de APIs REST:** Integração com serviços externos via `HttpClient` e tratamento de fluxos assíncronos.
* **Autenticação & Login Social:** Configuração e implementação de Login Social (Google e outras plataformas).
* **Arquitetura de Micro-Frontends:** Desenvolvimento de arquitetura distribuída e desacoplada utilizando **Module Federation**.

---

## 🎯 Recursos e Conceitos do Framework

- **Componentes e Diretivas:** Interfaces reutilizáveis, reativas e dinâmicas.
- **Data Binding:** Sincronização em tempo real entre o modelo e a view.
- **Roteamento & Lazy Loading:** Navegação otimizada e carregamento de módulos/componentes sob demanda.
- **Serviços & Injeção de Dependências:** Arquitetura limpa, modular e altamente testável.
- **Formulários Reativos e Template-Driven:** Validações complexas e manipulação flexível de formulários.
- **RxJS & Programação Reativa:** Manipulação avançada de fluxos de dados e eventos assíncronos.
- **State Management:** Gerenciamento centralizado e performático do estado da aplicação.
- **Micro-Frontends:** Integração de múltiplas aplicações Angular via Module Federation.

## 📋 Pré-requisitos para rodar o projeto

Para executar o projeto localmente, você precisará ter instalado em sua máquina:

- [Node.js](https://nodejs.org/) (versão LTS recomendada compatível com Angular 19)
- [Angular CLI](https://angular.dev/tools/cli) (`npm install -g @angular/cli`)
- Gerenciador de pacotes **npm** ou **yarn**

---

## 🚀 Como Executar o Projeto

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd SEU-REPOSITORIO
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   ng serve --open
   # ou
   npm run start
   ```

5. **Acesse no navegador:**
   A aplicação estará disponível em `http://localhost:4200/`.
